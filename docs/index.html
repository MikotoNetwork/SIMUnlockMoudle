基于现代 libxposed API 102 构建的极简 LSPosed 模块。通过 SystemUI 标准广播与卡槽兜底检测自动完成 SIM 解锁，密码经设备硬件特征派生密钥本地加密，日志零明文泄露。

核心特性

围绕稳定、轻量与隐私安全设计的每一处细节

现代 libxposed API 102

采用全新拦截器链模型与 ExceptionMode.PROTECTIVE 保护模式，彻底告别旧版 XposedBridge，Hook 异常不会导致 SystemUI 崩溃。

跨 ROM 通用兼容

不依赖各家 ROM 私有锁屏类，通过 SIM_STATE_CHANGED 广播与开机 3 秒主动卡槽检查双重触发，已实测兼容 ColorOS 等定制系统。

单卡 / 双卡独立配置

主界面自动识别设备卡槽数量，为 SIM 1 与 SIM 2 分别加密存储 PIN 码；留空的卡槽自动跳过，互不干扰。

单次尝试防锁卡

按卡槽索引记录解锁状态，每次开机每个卡槽严格仅尝试解锁一次，避免因忘记更新 PIN 导致反复重试耗尽次数并触发 PUK 锁定。

硬件特征派生密钥

组合设备稳定硬件属性、应用 UUID 盐值与 16 字节随机 Salt，经 100,000 次 PBKDF2-HMAC-SHA256 派生 AES-256-GCM 密钥，换机无法直接解密。

零敏感日志输出

运行日志仅记录注入状态、卡槽编号与系统返回的状态码（如 resultType=0），绝不输出任何 PIN 明文或密文。

安全加密与跨进程同步链路

全程本地处理，无任何网络权限与云端传输

STEP 01
主界面输入 PIN

按卡槽分别录入，密码框遮蔽输入，空值自动清理对应卡槽记录。

STEP 02
PBKDF2 派生密钥

结合硬件特征 + UUID 盐值 + 随机 16B Salt，100,000 次迭代生成 AES-256 密钥。

STEP 03
RemotePreferences

AES-256-GCM 加密为 Base64 密文，经 libxposed Service 安全同步给框架。

STEP 04
SystemUI 单次解锁

开机检测到 PIN 锁后内存解密并调用 supplyIccLockPin，每卡限试一次。

快速使用指南

四步完成部署，支持 Android 13+ 与 Modern Xposed API 102

1

下载并安装原版 APK

从 GitHub Releases 下载官方签名安装包并完成安装。

2

在 LSPosed 中启用并勾选作用域

打开 LSPosed 管理器 → 模块，启用本模块并确认已勾选 系统界面 (com.android.systemui)。

3

加密保存各卡槽 PIN 码

打开模块主界面，为需要自动解锁的卡槽输入 PIN（不解锁的卡槽留空），点击「加密保存」。

4

重启设备生效

重启手机后自动解锁；可在 LSPosed 日志中搜索 SimAutoUnlock 查看结果码。
